# `benchctrl.dashboards`

Intentionally empty at v1.0.

This package is reserved for v1.x and later graphical-dashboard work:
real-time matplotlib displays, web-based live visualisations,
multi-pane oscilloscope-style UIs against ongoing recordings, etc.

Today's graphical output is one-shot matplotlib PNGs rendered by
`benchctrl.recording.Recording.plot()` and the
`plot_recording` MCP tool. As true interactive dashboards land,
they go here.
